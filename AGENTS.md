# Instructions for AI Coding Assistants

These instructions apply to GitHub Copilot and other AI coding assistants
working in this repository.

- Read the relevant project documentation before implementing a feature.
- Respect the technology stack once the team has selected it.
- Do not introduce a framework or dependency without explaining and
  justifying the need.
- Prefer simple, readable, maintainable solutions.
- Keep changes focused, modular, and limited to the files they require.
- Avoid unnecessarily modifying unrelated files.
- Suggest appropriate tests for generated or changed code.
- Never invent environmental facts or scientific measurements.
- Use clearly labeled placeholder values when real data is unavailable.
- Never include API keys, tokens, credentials, or other secrets in generated
  code.
- Ask for clarification when a significant architectural decision is
  unresolved.

No engine-specific coding instructions are established yet.
