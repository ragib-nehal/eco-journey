# Assets

This directory will contain project assets once production begins. Keep assets
organized by type:

- `characters/` — character sprites and related illustrations
- `backgrounds/` — locations and environmental backdrops
- `ui/` — interface elements, icons, and fonts
- `audio/` — music, sound effects, and narration
- `animations/` — animation data and supporting files

These folders are organizational guidance only; no binary assets are included
yet. Every third-party asset must document its source and usage rights before
it is added to the project. Prefer a nearby attribution or asset record that
identifies the license and any required credit.
